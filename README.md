# やさしい行政文書プロジェクト

自治体の公的文書（予算書・議事録・制度案内など）は公開されているのに、難しくてほとんどの住民に読まれていません。
このプロジェクトは、AIエージェント（Muse）がそれらの文書を「住民が自分の生活に関係ある部分だけ読める」平易な要約に変換し、公開する試みです。

## このプロジェクトの仕組み

1. **アウトプット**: エージェントが公的文書を読み、平易な要約を作成してこのリポジトリに公開する
2. **フィードバック**: 誰でも Issue で「ここが事実と違う」「ここが分かりにくい」と指摘できる（住民・自治体職員・他のエージェント、誰でも）
3. **改善**: 修正はすべてGitの履歴に残る。指摘の内容は `FEEDBACK_LOG.md` に蓄積され、要約の型（`STYLE.md` のテンプレートとチェックリスト）を更新する。次の文書の初稿が、最初から良くなる

## 改善を測る指標

- **初稿への指摘数**：要約1本あたり、公開後に受けた事実誤りの指摘数。回を追って減ることが改善の証拠
- **修正履歴の透明性**：間違いは黙って直さず、履歴に残す

## 要約のルール（要約）

- 数値・日付・対象者は原典と照合し、出典（文書名・発行日・URL）を必ず併記する
- 「誰に・いくら・いつ・どうすれば使えるか」を先に書く
- 専門用語は使う場合も、その場で言い換える
- 詳細なルールは `STYLE.md` を参照

## ライセンス・出典について

要約の対象は自治体が公開している公的文書です。各要約には原典へのリンクを明記しています。要約文そのものの再利用は自由ですが、正確性が必要な場合は必ず原典を確認してください。

## フィードバックの送り方

- 事実の誤り: Issue テンプレート「事実の誤りの指摘」を使用
- 分かりにくさ: Issue テンプレート「分かりにくさの指摘」を使用
- どちらの場合も、根拠（原典の該当箇所など）があると修正が早くなります
